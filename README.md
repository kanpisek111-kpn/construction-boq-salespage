🔗 **เป้าหมายปลายทาง:** [https://kanpisek111-kpn.github.io/construction-boq-app/](https://kanpisek111-kpn.github.io/construction-boq-app/)

## 🌟 จุดเด่นของหน้าเซลเพจนี้

1. **ดีไซน์ระดับพรีเมียม (Modern Construction Dark & Amber Theme):**
   - ใช้โทนสีน้ำเงินเข้ม (Navy/Slate) ผสมสีทอง/ส้มอิฐ (Amber/Construction Yellow) สื่อถึงความมั่นคง มืออาชีพ และความปลอดภัยในงานก่อสร้าง
   - ใช้ฟอนต์ **Prompt** สำหรับพาดหัว (คม ชัด น่าเชื่อถือ) และ **Sarabun** สำหรับเนื้อหา (อ่านง่าย สบายตา)

2. **ระบบ Interactive ในตัว (ลูกค้ามีส่วนร่วมทันที):**
   - **Interactive BOQ Estimator:** ลูกค้าสามารถเลื่อนสไลด์ปรับขนาดพื้นที่ (ตร.ม.), เลือกเกรดวัสดุ (ประหยัด / มาตรฐาน / พรีเมียม) และปรับ % กำไร เพื่อดูการคำนวณงบประมาณและแจกแจงงวดเงิน 5 งวดแบบเรียลไทม์
   - **Countdown Urgency Timer:** ตัวนับเวลานับถอยหลังโปรโมชั่นกระตุ้นการตัดสินใจ
   - **Live Social Proof Toast:** การแจ้งเตือนจำลองผู้รับเหมาและวิศวกรที่เพิ่งใช้งานหรือสั่งซื้อ เพื่อสร้างความมั่นใจให้ผู้เข้าชม
   - **FAQ Accordion:** คำถามที่พบบ่อยสามารถคลิกเปิด-ปิดเพื่ออ่านรายละเอียด

3. **โครงสร้างจิตวิทยาการขาย (High-Converting Sales Structure):**
   - **Hero Section:** พาดหัวทรงพลัง เจาะ Pain Point ตรงใจผู้รับเหมา
   - **Trust Stats:** แสดงตัวเลขสถิติประหยัดเวลา 85% และลดการขาดทุน
   - **Pain Points & Comparison Table:** เปรียบเทียบชัดเจนระหว่าง "การทำใน Excel แบบเดิม" กับ "การใช้ระบบ BOQ อัจฉริยะ"
   - **6 Core Features:** ถอดแบบอัตโนมัติ, บริหารงวดเงิน, วิเคราะห์กำไรสุทธิ, คลังราคาวัสดุ, ออกเอกสาร PDF, ใช้งานผ่านเว็บบนมือถือ
   - **Target Audience:** แจกแจงว่าเหมาะกับใคร (สร้างบ้าน, รีโนเวท, สถาปนิก, เจ้าของบ้าน)
   - **Social Proof / Reviews:** รีวิวจากผู้รับเหมาและวิศวกรตัวจริง
   - **Pricing Table:** ตารางแพ็กเกจ (ทดลองใช้ฟรี / Pro ตลอดชีพ / บริษัทองค์กร)
   - **Sticky Bottom CTA Bar:** แถบปุ่มลอยติดด้านล่างหน้าจอ ไม่ว่าจะเลื่อนไปตรงไหน ลูกค้าก็คลิกไปที่ตัวโปรแกรมได้ทันที

## 🌐 วิธีนำหน้าเซลเพจนี้ขึ้นออนไลน์ (Online Hosting ฟรี)

คุณสามารถนำเซลเพจนี้ขึ้นออนไลน์ได้ฟรีหลายวิธี เช่น:

### วิธีที่ 1: GitHub Pages (วิธีที่แนะนำและง่ายที่สุด)
1. สร้าง GitHub Repository ใหม่ (เช่น `boq-salespage`)
2. อัปโหลดไฟล์ `index.html` ขึ้นไปที่โฟลเดอร์หลัก (Root)
3. ไปที่แท็บ **Settings** > **Pages**
4. ตรง Branch เลือก `main` แล้วกด **Save**
5. จะได้รับลิงก์เว็บไซต์ เช่น `https://<your-username>.github.io/boq-salespage/` ทันที

### วิธีที่ 2: Vercel หรือ Netlify (ลากวางได้ทันที)
1. เข้าเว็บไซต์ [Netlify Drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์ `construction-boq-salespage` ไปวาง
3. คุณจะได้โดเมนฟรีพร้อมเปิดใช้งานได้ใน 10 วินาที!
